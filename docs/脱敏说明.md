## 六、刻意保留的项及理由

| 保留项 | 类别 | 理由 |
|---|---|---|
| `ttwid` / `passport_csrf_token` / `msToken` / `SUBP` / `SSOLoginState` 等 | Cookie **名称** | 只是平台公开的 Cookie 名，代码里从未携带其值；值全部在运行时从用户浏览器读取并存于本机 `%APPDATA%`，不入库、不写源码 |
| `xsec_token` / `sec_uid` 等**变量名与注释** | 标识符 | 脱敏只替换「值」，字段语义必须保留，否则代码逻辑被破坏 |
| `weibo.com` / `douyin.com` / `xiaohongshu.com` 等平台域名 | 公开域名 | 这类域名是各平台的公开入口，属协议常量而非私密信息；替换会让解析/采集逻辑整体失效。如需彻底脱敏，请用 `--strict` 生成严格副本 |
| `65f0a1b2c3d4e5f60718293a` 等 24 位十六进制 ID、`7300000000000000000` 等长数字 ID | 人工构造样例 | 位串呈 `0a1b2c3d4e5f` / `a1b1c2d3e4f5a6b7c8` / 全零后缀等明显键盘序列特征，判定为测试用例自造，非真实账号；保守起见严格模式下仍会替换 |
| `C:\out\a\img01.jpg`、`C:\` 等 | 通用示例路径 | 不含用户名等本机标识，属测试夹具内的通用占位路径 |

## 十、使用提示

- 本副本**结构、文件名、代码逻辑与原工程完全一致**，仅字面量被替换。
- 若要在本机运行副本内的测试，请先把占位符按第三节映射表回填为同类型的合法值
  （例如 `WEIBO_UID_PLACEHOLDER` 需填回 10 位纯数字，`DOUYIN_SEC_UID_PLACEHOLDER` 需填回 `MS4wLjABAAAA` 开头的字符串），
  否则少数依赖 ID 字符形态的解析用例会因占位符不是数字/不是 base62 而报错——这是脱敏的预期代价，不是代码缺陷。
